## 🚀 Quick Start

### Prerequisites
- Node.js (v12 or higher)
- npm (Node Package Manager)
- Cognigy endpoint URL and token

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/lalitnayyar/cognigysocketio.git
   cd cognigysocketio
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Configure Environment**
   Create `.env` file:
   ```env
   COGNIGY_ENDPOINT=wss://endpoint-amna.cognigy.cloud
   URL_TOKEN=your_url_token
   SESSION_ID=your_session_id
   USER_ID=your_user_id
   PORT=3000
   ```

4. **Start Application**
   ```bash
   npm start
   ```

5. **Access Interface**
   Open `http://localhost:3000`

## 💻 Usage Guide

### Avatar Customization

1. **Changing Avatar Style**
   - Click the user icon next to send button
   - Choose from 10 unique styles
   - Watch real-time updates across messages
   - Style persists during conversation

2. **Message Interactions**
   - Hover over messages for animations
   - See rainbow borders on avatar hover
   - Experience smooth transitions
   - Enjoy dynamic color effects

### Chat Features

1. **Voice Input**
   - Click microphone icon to start recording
   - Speak your message clearly
   - Edit transcribed text if needed
   - Click microphone again to stop recording
   - Send message normally after transcription

2. **Sending Messages**
   - Type in the input field
   - Press Enter or click send
   - See instant message delivery
   - Watch dynamic styling apply

3. **Viewing History**
   - Scroll through past messages
   - Color-coded by sender
   - Timestamps on all messages
   - Smooth scroll animations

4. **JSON Monitor**
   - Toggle between panels
   - Watch real-time updates
   - See formatted JSON
   - Dark theme for readability
